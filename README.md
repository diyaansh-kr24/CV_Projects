# CV_Projects

A collection of computer vision projects built as part of a structured learning program, covering classical image processing techniques and deep learning-based approaches using Python.

---

## 📁 Projects

### 1. [Pencil Sketch Generator](./pencil_sketch_generator/)
Converts color images into realistic black-and-white pencil sketches using classical image processing. Implements grayscale conversion, Gaussian blurring, and manual Color Dodge blending entirely with OpenCV and NumPy.

### 2. [Hough Circle Detection](./hough_circle_detection/)
Detects circular objects in images using OpenCV's Hough Circle Transform. Includes image preprocessing, annotated visualizations, and statistical exports (circle count, min/max/mean radius) for each input.

### 3. [Dogs vs Cats Classifier](./dogs_vs_cats_resnet18/)
Binary image classifier built with transfer learning on a pre-trained ResNet18 architecture using PyTorch. Achieves **96% test accuracy** with data augmentation, learning rate scheduling, and model checkpointing.

---

## 🛠️ Tech Stack
Python, OpenCV, NumPy, PyTorch, torchvision, Matplotlib, scikit-learn
